# Демонстрационный прогон: онлайн-школа «Профиль»

Реальный сквозной прогон системы на брифе, которого она не видела:
запрос → факты с дословными цитатами (обе ловушки пойманы: два определения
«активного ученика», разные знаменатели 22%/31%) → четыре варианта с точным
скорингом → выбор человека (повторные покупки) → две стратегии, обещания,
пилот 2×10 000 с контрольной группой → утверждение человека → файлы.

- brief-profil.pdf — исходный бриф (условная компания, числа учебные)
- situation.md / options.md / research-plan.md — разбор и варианты
- product-strategy.md / communication-strategy.md / стратегия-повторные-покупки.md — итоговые стратегии
- validation-plan.md / decision-bundle.json — план проверки и пакет решения

Оба ключевых решения (направление и утверждение) зафиксированы как живые
согласования человека с датой, временем и дословной цитатой ответа.
