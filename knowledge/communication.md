# Методика: коммуникация

Аудитория/ситуация → барьер → сообщение → доказательство → роль канала → целевое действие → способ проверки.

Promise matrix: обещание → текущая возможность продукта → evidence/ограничения → допустимая формулировка. Planned не available. Нельзя усиливать обещание ради убедительности или подменять реализацию дорожной картой.

Сообщения и продуктовая стратегия опираются на общие проверенные основания. При изменении масштаба/сегмента перепроверяются обе стратегии, а не только итоговый абзац.
