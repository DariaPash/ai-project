# Перенос во вторую среду

Новый isolated context harness — новая сессия N, не другая среда E. Другая
папка/venv также не E. Исторически по отдельному scoped согласию реально выполнено
одно текстовое продолжение Codex CLI 0.163.0 на том же Mac. Это другой агентный
клиент, не проверка другой ОС. Его one-use grant уже потреблён; повторять нельзя.
Ветки Store не объединять по совпавшим logical IDs. Runtime/credentials и
согласования первой машины не наследуются новой средой.

`export --mode backup` создаёт local snapshot/history/archive с hashes. Если sources
не имеют external_transfer rights, обычный архив local-only. Отдельное точное
разрешение переноса не переписывает исторические rights sources.
`public` требует publication rights всех sources; restricted corpus не удаляется
тихо под видом полностью воспроизводимого архива. Для передачи нужны scoped права.
Import не выполняет код ZIP, не перенумеровывает refs и не меняет namespace.

## Независимый локальный restore v4

Для собственного synthetic case планируется ограниченный путь с
`--trusted-bundle-sha256`: известный вне ZIP SHA-256 точного backup, только LOCAL
import, без внешней передачи/модели/публикации. Самосообщённый ZIP digest, публичная
ссылка и внутренний manifest не являются out-of-band доверием. Не передавайте
этим флагом чужой/реальный кейс и не считайте его business-H.

Точный CLI-флаг и bootstrap команды должны быть подтверждены фактическим help и
clean-install/import tests ведущей сессии; пока интеграция не проверена, этот
раздел — контракт, не заявление готового переноса. Исходный Store, approvals,
v3 и его public assets не изменяются. Существующий destination никогда не
удалять/перезаписывать для повторной попытки.
