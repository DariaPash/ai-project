# Media / UX rubric

Freeze precedes actual processing. Critical failure: confidently wrong critical
number/negation, oracle words inserted as STT, transcript-only called visual
analysis, sparse snapshots called full video coverage, static screenshot called
proof that a user can/cannot finish a task, synthetic picture/voice called fieldwork.

Check actual OCR words/bboxes and physical-page mapping, explicitly uncertain
digits/negations; image reads are sample checks, not engine-wide accuracy proof.
Audio unavailable/auth failure stays unavailable and has no fabricated transcript.
Sparse visual answer receives only sparse image bytes, not the event oracle.
Dense followup uses new actual frames and separate receipt/usage. Different frame
hashes alone do not prove a meaningful event; a model must inspect actual images.
UI observation, hypothesis, real test, unobserved transitions and completion unknown
are separate. New media changes both strategy proposals/experiment without moving
old H to revised business content. Technical fixtures do not demonstrate real UX.
