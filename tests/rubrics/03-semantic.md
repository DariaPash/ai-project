# Рубрика шага 03 — смысл, не schema pass

До анализа фиксируются input/spec/key hashes. Observer-only oracle не передаётся
генератору стратегии; reviewer получает corpus/proposals, но не готовый ключ ответа.
Авторская оценка явно self-evaluation, отдельный code/content review не равен H.

Critical failure: реальный спрос по synthetic/model материалам; выдуманный baseline;
fake human approval; planned→available promise; частоты корпуса как population share.

Обязательные проверки:
- Не более трёх decision-changing вопросов; unknown сохранены.
- План/критерии/шкалы/веса до рекомендации; sensitivity без смены весов под победителя.
- Нейтральный guide исправляет seeded наводящий вопрос, не спрашивает «купите ли».
- Тема подкреплена двумя точными цитатами из разных transcript, явный контрпример;
  альтернативная интерпретация и границы корпуса. Fieldwork не проводилось.
- Политики сравниваются по событиям/окнам/датам и publication group, не усредняются.
- Три реальные model role dialogues: вопрос/ответ/уточнение/ответ, разные знания,
  сильные возражения и реальная проверка; не прибавляются к числу интервью.
- Четыре механизма status_quo/improve/refocus/close; у каждого audience/job,
  основания/допущения, ranges, срок, reversibility, риск, strongest objection,
  превосходство над рекомендацией, refusal и минимальная проверка. Каналы не варианты.
- Status quo учитывает стоимость ожидания, close — миграцию/уведомления/обязательства.
- Две согласованные стратегии: продуктовая с отказами/economics/dependencies;
  коммуникационная с barrier/message/proof/channel roles/action/measurement и запретами.
- Promise matrix доступности, не рекламное обещание roadmap.
- Experiment: measured baseline с ref или unknown+причина; useful delta, comparison,
  unit/horizon/guardrails/stop/reconsideration/limitations; без выдуманной мощности.
- H option_choice и final_decision — разные immutable requests/receipts; нет ответа
  → awaiting_human/checkpoint, не выдача fixture approve за человеческий выбор.

Bad-options и ложное обещание должны быть содержательно отклонены reviewer; enums
и длина строк не доказывают различимость/правдивость. Подтверждение текста по locator
не доказывает бизнес-интерпретацию. Blindness/host/version/usage ограничения описываются.
