# Исходная запись и статус публикации

Это сырые результаты новой PTY-сессии v5. `commands.json`, `session.cast`,
`terminal-frames.json` и выбранные полные кадры сохранены без переписывания вывода.
`replay.html` — локальный просмотр записанных состояний; его JavaScript не исполняет
команды. Браузерное выполнение HTML не проверено; проверенный deliverable — MP4.

`video-manifest.json` создан **до публикации**. Его `published=false` и
`submitted=false` — историческое состояние capture, не текущий статус GitHub.
Факт публикации устанавливается отдельной квитанцией и скачиванием без авторизации.
Юридическая отправка действительно не выполнялась.

В исходной папке capture MP4, HTML и manifests лежали рядом. Здесь MP4 доступен
на уровень выше: `../cli-demo.mp4`, а PDF — `../description-final.pdf`.
Hashes в сыром manifest относятся к исходным bytes, а не к новой структуре папок.
Дополнительные пояснения/проверки после упаковки могут присутствовать только
в репозитории, не внутри замороженных ZIP. Их отсутствие не меняет archive manifest.
