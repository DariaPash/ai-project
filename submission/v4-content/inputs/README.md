# Самостоятельный вход, не скрытая test fixture

`brief.json` — новый учебный бриф без ссылок на developer paths. Скопируйте его
в `cases/test-quickstart/input/brief.json` нового локального проекта после `init`.
Используйте `record --kind brief` с revision из свежего `status`, затем `validate`.
Полные команды и ограничения — корневой README. Эти данные не запускают модель,
не разрешают external transfer, интервью, обработку реальных записей или публикацию.

Не копируйте сюда private customer data. Две стратегии сохранённого demo берутся
из отдельно проверенного backup/readable-case, не выводятся из этого брифа.
