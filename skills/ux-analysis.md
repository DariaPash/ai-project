# UX analysis procedure — ux-v1

Input: permitted immutable screen/frame ART+hash, source/time/page mapping,
dimensions/orientation, current case/plan and allowed visual host.
Procedure: actually open the image, identify visible region in top-left pixels,
record visible_observation separately from hypothesis and a real test. State which
journey transitions were not observed. A visible NEXT button says nothing about
its functional behavior, task completion, user identity or speed.
Output: ux_observation/ux_journey with pinned refs, bbox, limitations and
completion_status=unknown. Incorporate findings in evidence/risks/promises of both
strategy proposals and experiment. Structural validate cannot prove image meaning.
Stop: no visual access, unreadable critical token, rights/budget missing, wrong
mapping/hash. Do not infer unseen UI states or use an observer key as perception.
